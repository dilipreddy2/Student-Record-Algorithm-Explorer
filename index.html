01 / THE PROBLEM

Searching student records can take time.

Schools and colleges manage many student records. Finding one student by roll number becomes slower as the record list grows. This project compares four algorithms that search for the same roll number and explains how each one works.

Why it matters

Quickly locating records helps staff and students access information efficiently.

What we compute

The matching student, number of comparisons, search steps, and theoretical time complexity.

04 / COMPLEXITY GUIDE

Understand the performance

AlgorithmBest caseAverage caseWorst caseExtra space
Linear SearchO(1)O(n)O(n)O(1)
Binary SearchO(1)O(log n)O(log n)O(1)
Jump SearchO(1)O(√n)O(√n)O(1)
Interpolation SearchO(1)O(log log n)*O(n)O(1)

n is the number of student records. *Interpolation Search's average-case bound assumes sorted, approximately uniformly distributed numeric keys. Binary, Jump and Interpolation Search use a sorted copy of the records.
